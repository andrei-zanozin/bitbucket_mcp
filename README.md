# Bitbucket PR Support

This project is intended to make everyday pull-request work simpler and more efficient
for team leads and development teams.

It supports the business workflow of:

- finding relevant pull requests and reviewing their history;
- understanding proposed changes and ongoing discussions;
- creating pull requests and contributing review feedback;
- managing discussion follow-up and review decisions.

The goal is to help teams review changes consistently, keep decisions visible, and
reduce the effort required to manage pull-request work.
